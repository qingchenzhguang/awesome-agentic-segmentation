Overview

A curated list of agents, harnesses, tools and resources for agentic image segmentation: systems that plan segmentation tasks, use vision tools, inspect masks and refine results, plus the integrations, benchmarks and workflows around them.

A project is in scope when all three hold: an agent decides something (which tool, which prompt, whether to stop), it calls a segmentation tool whose artifact it receives, and that artifact feeds back into the next action. A name containing “agent” is not evidence of agency.

This is not a catalogue of segmentation models, datasets or papers. Model backends appear only where an agent can call them; plain models are linked from Related.

Agents & Applications

Complete systems that decide what to do next, call a segmenter or an editor, look at the result and continue.

VASA paper

Training-free vision-harnessing agent for open ad-hoc segmentation: a VLM coordinates SAM 3 through planning, mask editing, scrutiny and error recovery while keeping one working mask persistent, inspectable and editable, and each run saves a trace viewer plus the tool-call history.

MedSAM-Agent paper

Qwen3-VL agent trained with multi-turn reinforcement learning to choose positive/negative points, boxes or an early stop for a medical segmenter (MedSAM2, SAM 2.1 or IMISNet), with single-image and batch inference scripts plus an RL training recipe.

MedicalPointsBoxes2D

MedSegAgent

Multi-agent AutoGen pipeline that maps a free-text medical segmentation request to dataset-specific nnU-Net models and label IDs through coarse-to-fine query filtering; a TotalSegAgent branch adds a runnable CT/MR segmentation service and web viewer.

MedicalText3D

SegAgent paper

MLLM trained to imitate human annotator trajectories: it issues a sequence of interactions to an interactive segmentor to build and refine a mask over several steps, and the weights, inference code and HLMAT trajectory dataset are released.

Natural imagesTextInteractive2D

VoxelSage paper

Self-hosted abdominal CT workspace where a natural-language agent drives imaging skills — segmentation through VISTA3D or TotalSegmentator, quantitative measurements, key-slice selection and interactive 3D reconstruction — behind a web UI and a documented Skills API.

MedicalTextInteractive3D

GenCellAgent

Training-free multi-agent system for cellular microscopy that routes each image to specialist or generalist segmenters (Cellpose, µSAM, ERNet, MitoNet, LISA, SegGPT) in a plan–execute–evaluate loop, with VLM-based quality scoring, human corrections and remembered configurations.

MicroscopyTextInteractive2D

ask-to-mask

Electron-microscopy organelle segmentation with an agentic refinement loop: a vision-language model writes the prompt, a generator draws the mask, and a VLM critic drives further iterations; SAM 3 point prompts and majority voting over orthogonal planes produce 3D masks.

MicroscopyTextPoints2D3D

FarmSeeker

Remote-sensing farmland segmentation agent that detects ambiguous regions, retrieves extra spatio-temporal imagery, reasons across dates and refines the mask with SAM 2.1; the accompanying GSFS-Bench is described as a global-scale farmland segmentation benchmark that supports reasoning–querying.

Remote sensingTextMasks2D

Refer-Agent paper

Collaborative multi-agent system for referring video object segmentation, where reasoning and reflection stages build and check the target description before SAM 2 propagates masks through the video.

VideoTextVideo

Agentic-SAM

Local ultrasound assistant that uses LangGraph tool orchestration over SAM 3, Medical-SAM3 and MedSAM2 to segment a PTMC bounding box, track it frame by frame through RFA video and post live tracking notes.

MedicalTextBoxes2D

MMedAgent paper

Multimodal medical agent trained to select and call specialist tools, including MedSAM for box-prompted segmentation and Grounding DINO plus MedSAM for text-prompted segmentation, across modalities that include MRI, CT, X-ray, histology and gross pathology.

MedicalTextBoxes2D

Change-Agent paper

LLM agent built on Lagent for bi-temporal remote-sensing images: it runs a multi-level change interpretation model to obtain change masks and descriptions, then answers follow-up questions about the changes.

Remote sensingText2D

LORE

Interactive agentic framework for 3D tumor segmentation: a policy observes the current mask, error residuals and shape descriptors, chooses which correction to request (click, box, scribble) and decides when to stop; the agent code is released, datasets and weights are not.

Harnesses & Frameworks

Reusable execution machinery: planning, code generation and tests, presets, traces, budgets, retries and evaluation splits.

VisionAgent

Library that plans a vision task, generates runnable Python that calls a large tool set — including SAM 2-based instance segmentation and video tracking — then tests the generated code and iterates until its test case passes. The repository description now marks the project deprecated in favour of LandingAI's Agentic Document Extraction.

agentic-segmentation

Research harness in which a general coding agent drives nnInteractive through a small set of seg_* tools to segment 3D MRI tumours; versioned harness presets, per-run traces, evaluation splits and a reproducible experiment log are part of the repository.

Tools & Integrations

Backends, MCP servers, skills, plugins and fixed pipelines an agent can call. The host and the backend are the point.

SAM 3

Meta's promptable concept segmentation model, released with inference and fine-tuning code and a bundled agent package in which a multimodal LLM calls tools such as segment_phrase, examine_each_mask, select_masks and report_no_mask over a bounded number of turns.

nnInteractive Agent paper

MCP server plus agent skill that gives a host agent (Claude Code, Codex or another MCP client) tools to prompt nnInteractive with scribbles, boxes and points, inspect 3D renders, undo and correct; a web demo and an agent benchmark are included.

SAM 3 Segmentation Skill

Agent skill that wraps SAM 3 behind staged CLI commands — find, click, everything, then audit, select, review-sheets, refine and export — so a host agent can review proposals, record reversible decisions and export PNG or COCO RLE masks.

Natural imagesTextPointsBoxes2D

ComfyUI Segmentation Agent

ComfyUI node that asks a vision LLM to break a character description into SAM 3 phrases, renders numbered mask candidates back to the model, and iterates until the model accepts a subset.

Natural imagesText2D

Grounded SAM 2

Demo pipelines that chain Grounding DINO or Florence-2 with SAM 2 for open-vocabulary image masks and video object tracking; a fixed pipeline rather than an agent, but a common segmentation backend in agent stacks.

proofreader-mcp

MCP server for image-centric proofreading of segmentation objects: it stores per-object screenshots as resources, ranks likely overmerge, oversegment, junk or misclassified cases for the host LLM to judge, and records human verdicts without running any model itself.

gfm-mcp

MCP server that exposes geospatial foundation model inference as tools — building extraction, water segmentation, object detection, change detection, zero-shot scene classification and embeddings — so an LLM agent can call remote-sensing segmentation from CPU.

MCP-Slicer

MCP server that lets a client drive 3D Slicer: list MRML nodes, execute Python inside the Slicer environment and capture screenshots of slice and 3D views, which supplies the visual feedback step of a ReAct-style loop.

napari plugin that exposes the viewer over MCP through a socket server, letting external agents inspect images and call napari's public API from a separate process.

MedMCP

On-premise agentic workspace for medical imaging: a locally served model plans the work, installable tool stacks do the computation, and a viewer shows images with segmentation overlays; by default nothing leaves the machine.

Evaluation & Benchmarks

What is measured matters: a script that runs, a model judging its own mask and accuracy against annotation are different things.

BIABench paper

Benchmark of 16 real bioimage-analysis tasks reconstructed from published studies, scored both on the produced result and on how the analysis was carried out; it ships adapters for coding agents such as Claude Code, Codex and DeepSeek Harness behind a single run(instruction, input_dir, output_dir) interface.

MicroscopyText2D

Benchmarks released inside listed projects:

  • nnInteractive Agent benchmark — Mean Dice of Claude Code and Codex driving nnInteractive on 14 public CT, MRI, PET and micro-CT images and 51 named targets, compared with single-click prompting and a text-only 3D model. nnInteractive Agent
  • HLMAT evaluation — Mask quality after human-like click trajectories, evaluated with the repository's IoU script on RefCOCO+ style splits. SegAgent
  • MSTT-199 and BEAMSTER splits — Coding-agent segmentation of soft-tissue tumours and brain metastases in 3D MRI, with per-run scores and trajectories. agentic-segmentation (coding-agent harness)
  • GSFS-Bench — Farmland segmentation with reasoning-and-querying over extra spatio-temporal imagery; dataset not yet released at verification time. FarmSeeker
  • MedSegAgent model-selection test set — Dataset-level hit rate of the routing pipeline, not mask Dice. MedSegAgent

Papers & Surveys

Research that directly informs segmentation agents. Where a project has a card, its paper is linked there instead.

RSAgent

Agentic multimodal LLM for text-guided segmentation that queries a segmentation toolbox, observes visual feedback and revises its spatial hypothesis over multiple turns; trained with cold-start SFT followed by agentic RL. No public code repository was found at verification time.

Natural imagesText2D

RSure-Agent paper

Remote-sensing agent that verifies tool observations before using them in later reasoning to reduce error propagation; the repository publishes the site, demo videos and paper, while the core tool-calling and verification code is still listed as unreleased.

Remote sensingText2D

VoxelPrompt

Vision-language agent for 3D medical images that emits executable instructions to a frozen segmentation network, adapting language prompts to volumetric tasks end to end. No public code repository was found at verification time.

MedicalText3D

SEER paper

Vision-language reasoning model for free-text 3D medical segmentation that grounds clinical language in image evidence and emits an executable target specification for a segmentation backbone; checkpoints, inference code and an evaluation split are released.

Patterns

Five things the entries have in common — and where they do not.

  • Two shapes. Either a trained model that emits prompts or actions (SegAgent, MedSAM-Agent, MMedAgent, LORE, RSAgent), or an external coding agent that drives tools through MCP, skills or a node (nnInteractive Agent, SAM 3 Segmentation Skill, ComfyUI Segmentation Agent, the MCP servers).
  • Feedback is mostly visual. 3D renders, slice screenshots, review sheets and VLM critiques are the common loop; a few systems act on mask geometry or a scalar state instead (MedSAM-Agent's updated mask, LORE's error residuals).
  • Medical imaging dominates. Six of the 13 agent entries and three of the 10 tools are medical; remote sensing and microscopy contribute distinct patterns — spatio-temporal retrieval and multi-agent tool routing.
  • Evaluation is thin. One independent benchmark (BIABench). Everything else reports author-run numbers, and several repositories ship no evaluation script at all.
  • Industrial inspection is missing. Searches returned segmentation models and anomaly detectors, but no agent with an inspectable tool loop, so the section is absent rather than padded.

Maintenance

The list is kept by reading, not by running. For each candidate: discover through GitHub and the linked awesome lists; read the project's own README and, where the entry claims a loop, the source files that implement it; then record the entry in data/resources.json. Nothing is cloned, installed or executed.

Status and the last-checked date live in that JSON record rather than on every card, so the page stays readable; deprecated or paper-only entries say so in their description. The current snapshot was last checked on 2026-11-05.
